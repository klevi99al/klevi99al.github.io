# Klevi Alushi portfolio

A static site with no build step. Open `index.html` in a browser, or upload the folder to any static host, such as GitHub Pages, Netlify, or Cloudflare Pages.

- `projects.js`: project titles, descriptions, images, and links
- `index.html`: page copy, experience, skills, and contact details
- `styles.css`: colors and layout (the variables are at the top)
- `main.js`: hero mini-game, project gallery, and other interactions

- `images/`: project screenshots and the portrait, one folder per project

Fonts load from Google Fonts, so they need an internet connection. The site is published at https://klevi99al.github.io with GitHub Pages. If you move it to another domain, update the `og:image` URL in `index.html`.
